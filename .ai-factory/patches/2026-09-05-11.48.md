# Bound hosted requests and document cloud lifecycle contracts

**Date:** 2026-09-05 11:48
**Files:** src/cloud/auth.rs, src/cloud/http.rs, src/cloud/mcp.rs, src/cloud/models.rs, src/cloud/store.rs, docs/cloud.md
**Severity:** high

## Problem

PR #64 review identified unclear compatibility/replay semantics, missing JWKS lifecycle coverage, incomplete request limits and missing caller/tool audit fields. Unknown signing-key IDs triggered unlimited parallel JWKS fetches, and the JWKS byte limit was applied after downloading the whole body.

## Root Cause

Cache expiry handled valid keys but not adversarial misses or concurrent refreshes. A post-download size check bounded accepted data without bounding the download. Existing cloud documentation described safeguards without their exact limits or operational exceptions.

## Solution

Serialize and throttle JWKS refresh attempts, including failures, and check each response chunk against the existing byte budget. Add MCP request, search-query, response and dispatch limits, a PostgreSQL tenant statement deadline, and structured audit records with hashed subject/target identifiers. Preserve long exact keys accepted at ingestion. Document schema compatibility, server-owned revisions, explicit force semantics, token-revocation limitations, ingress quotas and the lack of collection pagination. Retain concrete module boundaries until an actual second implementation exists.

## Prevention

Exercise random-key/concurrent refreshes and unfinished oversized streams before fixing cache boundaries. These regressions reproduced three upstream requests instead of one and timeout instead of early size rejection; excessive search arguments also passed before the fix. Test exact and one-over byte limits, multibyte arguments, JSON escaping, A → B → A replay, server-owned audit-field immutability and forced restoration. Run PostgreSQL tests with explicit restricted-runtime and administrator URLs. Further scale testing should measure collection aggregation memory before adding pagination.
