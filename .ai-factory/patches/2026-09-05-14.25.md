# Bound cloud collection reads and separate forced-push authorization

**Date:** 2026-09-05 14:25
**Files:** src/cloud/auth.rs, src/cloud/store.rs, src/cloud/http.rs, src/cloud/mcp.rs, src/cloud/client.rs, src/cli/mod.rs, docs/cloud.md, docs/cli.md
**Severity:** high

## Problem

The second PR #64 review identified that collection reads loaded entire workspaces before the response cap, normal push credentials could override conflicts, and direct store calls could bypass snapshot validation. The reviewer also questioned expired-key behavior and advisory-lock hash collisions.

## Root Cause

A wire-size check does not constrain database payload transfer or application aggregation. Force was treated only as a concurrency option rather than a separate permission, and validation relied on upstream callers. The retained JWKS cache was confused with usable cached keys, although each lookup already checks TTL.

## Solution

Check a 100-project/4 MiB budget in a single bounded PostgreSQL query, suppressing payloads on overflow; reuse the bound for context, graph and event collections. Return an actionable typed limit error through MCP. Require both push and push-force scopes before forced writes or no-op checks. Revalidate schema, canonical byte size and hash at the store entry. Strengthen authenticate-path coverage proving expired keys stay unusable after a refresh error and during cooldown. Document harmless extra contention from advisory hash collisions rather than changing the lock scheme.

## Prevention

Regression checks reproduced force returning 200 instead of 403, 101 projects loading successfully, direct invalid input reaching database acquisition, and a limit error returning 500 instead of actionable 422. Cover exact/over byte and count boundaries, retained data after denied force, exact-key access to large workspaces, scope prefixes, event ordering and canonical fixtures in concurrent-write tests. Size/authorization protections should sit before the expensive operation or state transition they guard. Add pagination when clients need complete collections larger than the fixed budget.
